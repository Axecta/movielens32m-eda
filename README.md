# MovieLens 32M — EDA

`movielens32m_eda.ipynb` — выполненный анализ полного датасета для рекомендательной системы фильмов. В каждом разделе: цель, код и результаты, краткий вывод.

Для повторного запуска установите `requirements.txt` и откройте ноутбук в Jupyter. Данные загружаются автоматически в `data/`; нужны несколько ГБ памяти и диска.

Источник и условия использования: https://files.grouplens.org/datasets/movielens/ml-32m-README.html
