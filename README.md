# MovieLens 32M — разведочный анализ

Чекпойнт 2 годового проекта, команда 129, ML-трек.

- [EDA.ipynb](EDA.ipynb) — выполненный анализ с таблицами, графиками и выводами.
- [practical_value.pdf](practical_value.pdf) — практическая применимость, риски и оценка результата заказчиком; одна страница A4.

## Покрытие требований

| Требование | Разделы EDA |
|---|---|
| Статистики числовых и категориальных признаков | 1 |
| Пропуски: количества, доли, гипотеза и обработка | 2, 4 |
| Ошибочные значения и связи таблиц | 2, 5, 14 |
| Выбросы и решение об обработке | 3, 6 |
| Распределения, сводные таблицы и связи с рейтингом | 7–12 |
| Попарные корреляции и scatter matrix | 17 |
| Временная проверка и холодный старт | 9, 12–16 |
| Выводы и применение результатов | После каждого блока; решения в конце раздела 17 |

Основные расчёты выполнены на всех 32 000 204 оценках. Для попарного анализа взяты 200 000 validation-событий; scatter matrix использует 3 000 полных строк. Seed=42. Признаки для анализа связей с таргетом рассчитаны только по train. Обучение моделей относится к следующему этапу.

## Повторный запуск

Проверено с Python 3.9.6. Сохранённые результаты доступны без запуска.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook EDA.ipynb
```

При первом запуске архив скачивается в `data/`; контрольные суммы CSV проверяются по описанию источника. Нужны несколько ГБ памяти и свободного диска. Данные исключены из Git.

[Требования чекпойнта](https://docs.google.com/document/d/1Izow1n6RTf-iP6MEXE3zVH9i5-gBoFUr4uJvCLKhh1U/edit) · [Описание и условия использования MovieLens 32M](https://files.grouplens.org/datasets/movielens/ml-32m-README.html).
